## Keywords

- **Tensors** 
    * A tensor is generally a single or multidimensional array of values. The dimensions of the array are usually referred to as its shape.
- **Device**
    * A device in PyTorch is a hardware component—such as a CPU or a GPU (CUDA)—where your tensors and neural network models are stored and computed
